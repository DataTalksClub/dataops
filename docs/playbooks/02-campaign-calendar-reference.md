# Campaign Calendar Reference & Phase Cadence

This document provides the standard 8-phase promotional schedule for Zoomcamp cohort launches, synthesized from `02-campaign-calendar.csv`.

## The 8 Campaign Phases

| Phase | Relative Period | Objective | Post Density | Primary Content Types |
| :--- | :--- | :--- | :--- | :--- |
| **0. Foundation** | `T-12 to T-9 weeks` | Market context, problem framing, category relevance before selling. | 1–2 posts/week | Problem framing, audience segmentation, instructor thesis, research questions. |
| **1. Awareness** | `T-8 to T-6 weeks` | Broad visibility, first-touch interest, domain explainers. | 2–4 posts/week | Coming-soon announcements, domain explainer, role/pathway, educational micro-lesson. |
| **2. Consideration** | `T-5 to T-3 weeks` | Decision support, curriculum walkthroughs, answering objections. | 3–5 posts/week | Main registration announcement, syllabus walkthrough, prerequisite FAQ, testimonials. |
| **3. Decision** | `T-2 wks to T-1 day` | Overcoming friction, live Q&A promotion, setup checklists. | 4–6 posts/week | Q&A announcement, syllabus deep dive, student project proof, setup guide, last calls. |
| **4. Launch Week** | `T+0 to T+6 days` | Cohort kickoff, stream attendance, module 1 start support. | 3–5 posts/week | Starts today post, launch stream link, module 1 start, setup troubleshooting. |
| **5. Active Cohort** | `T+7 to T+Course_End` | Weekly learning rhythm, homework support, community retention. | 2–4 posts/week | Module announcements (Mon), tool deep dive (Wed), homework reminder (Fri). |
| **6. Project Phase** | Midterm & Capstone | Project kickoffs, scope rubrics, peer review instructions. | 3–5 posts/week | Project launch, evaluation rubric, peer review etiquette, project showcases. |
| **7. Wrap-Up & Evergreen** | `T+End to +28 days` | Celebrating completions, issuing certificates, next cohort waitlist. | 1–2 posts/week | Results & completion stats, project gallery, testimonials, self-paced CTA. |

## Weekly Cadence During Active Cohort

Each module runs for one week with a consistent posting and support rhythm:

- **Monday 09:00 UTC:** Module N Announcement across Slack, Telegram, LinkedIn, X, and Email.
- **Wednesday 14:00 UTC:** Educational Micro-Lesson or Tool Deep Dive explaining that module's practical application.
- **Friday 12:00 UTC:** Homework deadline reminder & Learning-in-public prompt ("Share what you built this week").
- **Following Monday 23:00 UTC:** Homework submission deadline closes strictly on `courses.datatalks.club`.
