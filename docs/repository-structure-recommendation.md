# DataOps Repository and Directory Structure Recommendation

This recommendation defines where DataOps product code, process knowledge,
workflow templates, assistant code, runtime artifacts, and infrastructure
live, and how ownership splits across the public app repo, the private
`DataTalksClub/dataops-knowledge` repository, `aws-infra`, and runtime
storage outside Git.
